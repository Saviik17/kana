# Kana 1,5 s

Appli web installable (PWA) pour lire le japonais vite : kana (hiragana et katakana, de base, accentués, combinés), sosies, 10 000 mots et kanji N5/N4.

Installation sur iPhone : ouvrir https://saviik17.github.io/kana/ dans Safari, puis Partager > Sur l'écran d'accueil.

## Données
